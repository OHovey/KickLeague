  <action>
    Add a new exported function `checkBudgetThresholds()` to `src/lib/pipeline/api-budget.ts`:

    1. Import `* as Sentry` from `@sentry/nextjs`

    2. Define two threshold constants at module level:
       - `const WARNING_THRESHOLD = 6000` (80% of 7,500 daily limit)
       - `const CRITICAL_THRESHOLD = 7000` (93% of 7,500 daily limit)

    3. Create `export async function checkBudgetThresholds(): Promise<void>`:
       - Call `getDailyCallCount()` to get current count
       - If count >= CRITICAL_THRESHOLD:
         - Call `Sentry.captureMessage()` with:
           - Message: `API-Football budget CRITICAL: ${count}/7,500 daily requests used`
           - Level: `'fatal'`
           - Extra context: `{ dailyCount: count, threshold: CRITICAL_THRESHOLD, dailyLimit: 7500 }`
         - Also `console.error()` the same message for log visibility
       - Else if count >= WARNING_THRESHOLD:
         - Call `Sentry.captureMessage()` with:
           - Message: `API-Football budget WARNING: ${count}/7,500 daily requests used`
           - Level: `'warning'`
           - Extra context: `{ dailyCount: count, threshold: WARNING_THRESHOLD, dailyLimit: 7500 }`
         - Also `console.warn()` the same message for log visibility

    4. This function should be called at the end of each cron route (Task 2 handles that wiring).
       Keep existing functions (logApiCall, getDailyCallCount, canMakePipelineCall) unchanged.
  </action>

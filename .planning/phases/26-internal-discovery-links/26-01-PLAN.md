    **StatCard.tsx changes:**
    Add an optional `href?: string` prop to StatCard. When provided, wrap the card's outer div in an anchor tag (`<a>`) with the href, maintaining the same visual appearance. Use the existing glow-card styling. The anchor should have `className` that includes the existing card classes. When no href, render as a plain div (current behavior).

    **queries.ts changes:**
    Update `TopScorerResult` to include `teamSlug: string`. In `getTopScorer`, add `teams.slug` to the select and map it to `teamSlug` in the return.
    Update `FormTeamResult` to include `teamSlug: string`. In `getFormTeam`, add `teams.slug` to the select and map it to `teamSlug`.
    Update `BiggestUpsetResult` to include `homeTeamSlug: string` and `awayTeamSlug: string`. In `getBiggestUpset`, add `homeTeam.slug` and `awayTeam.slug` to the select.

    Note: The types from queries.ts are NOT in a 'use server' module -- they're in `src/lib/stats/queries.ts`, a plain module, so they CAN be imported by client components.

    **actions.ts changes:**
    The `StatHighlightsResult` interface uses the query types. Since we added slug fields to the query result types, they will automatically flow through. No changes needed to actions.ts unless the localization step strips them -- verify the spread operator `{ ...topScorer, teamName: ... }` preserves slug fields (it does, since spread copies all properties).

    **StatHighlights.tsx changes:**
    Use `useLocale()` (already imported) to build href paths for each stat card:
    - Top Scorer card: `href={`/${locale}/leagues/${league}/stats/top-scorers`}` -- links to the stats leaderboard for the current league. This is independent of the player data and always valid when data exists.
    - Biggest Upset card: `href={`/${locale}/matches/${data.biggestUpset.fixtureId}`}` -- links to the match detail page for the upset match. The `fixtureId` is already in BiggestUpsetResult.
    - Best Form card: `href={`/${locale}/teams/${data.formTeam.teamSlug}`}` -- links to the team page for the form team. Uses the new teamSlug field.

    Only set href when data is non-null (when `isEmpty` would be false).

    **i18n changes:**
    Add to StatHighlights namespace in all 5 locale files:
    - `"viewTopScorers": "View top scorers"` (en)
    - `"viewMatch": "View match"` (en)
    - `"viewTeam": "View team"` (en)
    Translate for es/de/it/fr. These are used as aria-labels on the card links.

    Actually, since the cards already have descriptive content (label, subject, stat), an aria-label is not strictly needed on the anchor -- the card content serves as accessible text. Skip the aria-label keys to keep it simpler.

  <files>docs/DNS_SETUP.md</files>
  <action>
Create `docs/DNS_SETUP.md` with a step-by-step checklist covering:

**1. Domain Purchase**
- Register domain (e.g. kickleague.com) from a registrar (Namecheap, Cloudflare Registrar, Google Domains, etc.)
- Ensure WHOIS privacy is enabled
- Note: domain propagation can take up to 48 hours

**2. Vercel Domain Configuration**
- Go to Vercel Dashboard > Project (KickLeague) > Settings > Domains
- Click "Add Domain"
- Enter the domain name (e.g. `kickleague.com`)
- Vercel will show the required DNS records

**3. DNS Record Configuration**
At your domain registrar's DNS settings, add:

For apex domain (`kickleague.com`):
- Type: `A`
- Name: `@`
- Value: `76.76.21.21` (Vercel's IP)

For www subdomain (`www.kickleague.com`):
- Type: `CNAME`
- Name: `www`
- Value: `cname.vercel-dns.com`

Note: If registrar supports ALIAS/ANAME records, use `ALIAS cname.vercel-dns.com` for apex instead of A record.

**4. SSL Verification**
- Vercel automatically provisions SSL via Let's Encrypt
- After DNS propagation, verify SSL at: `https://kickleague.com`
- Check for padlock icon in browser
- If SSL fails, check Vercel Domains page for status/errors

**5. Environment Variable Updates**
- Update `NEXT_PUBLIC_SITE_URL` in Vercel env vars to the production domain (e.g. `https://kickleague.com`)
- This affects: SEO metadata, sitemap.xml, OG image URLs, canonical links, hreflang alternates
- Redeploy after updating

**6. Post-DNS Checklist**
- [ ] Domain resolves to Vercel deployment
- [ ] HTTPS works with valid SSL certificate
- [ ] www redirects to apex (or vice versa, configured in Vercel)
- [ ] `NEXT_PUBLIC_SITE_URL` updated and redeployed
- [ ] Sitemap accessible at `https://kickleague.com/sitemap.xml`
- [ ] robots.txt accessible at `https://kickleague.com/robots.txt`
- [ ] OG images load correctly (test with https://developers.facebook.com/tools/debug/)
- [ ] Google Search Console: add new property for domain, verify ownership
- [ ] Update AdSense site URL if previously submitted with a different domain
- [ ] Update Sentry project URL/allowed domains if needed

Include notes about DNS propagation times and how to check with `dig` or `nslookup` commands.

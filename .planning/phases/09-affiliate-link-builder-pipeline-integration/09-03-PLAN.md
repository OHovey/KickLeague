  <action>
    Create `src/lib/pipeline/refresh-odds.ts` following the pattern of the seed script but adapted for cron execution.

    **Core function: `refreshOdds()`**

    1. Import `fetchOddsForSport` from `@/lib/odds-api/client`
    2. Import `buildAffiliateLink` from `@/lib/affiliate/link-builder`
    3. Import `SPORT_KEY_MAP` from `@/lib/odds-api/sport-keys`
    4. Import `getDb, isDatabaseConfigured` from `@/db/connection`
    5. Import `fixtureOdds` from `@/db/schema`
    6. Import `eq` from `drizzle-orm`
    7. Import `fixtures` from `@/db/schema`

    **Logic:**
    - For each league in SPORT_KEY_MAP (5 leagues), call `fetchOddsForSport(sportKey)`
    - For each event returned, find the matching fixture in the DB by matching home_team + away_team names (use the same team name resolution approach as the seed script, but simpler: query fixtures by kickoff date range since these are upcoming fixtures)
    - Actually, a simpler approach: match by the existing fixture's teams. The cron should only update odds for fixtures that ALREADY exist in the DB (created by API-Football polling or seed script). Query fixtures WHERE status = 'scheduled' AND leagueId matches, then match by team names.
    - For each bookmaker in each event:
      - Find h2h market outcomes
      - Call `buildAffiliateLink()` for home, draw, away outcomes
      - Upsert into `fixture_odds` with enriched links (same upsert pattern as seed-odds.ts)
    - Track and return summary: `{ leaguesPolled, eventsProcessed, oddsUpserted, affiliateEnriched, quotaRemaining }`
    - Log quota after each league fetch

    **Team matching strategy:**
    - Load all teams from DB once (like seed script does)
    - Use the same ODDS_TO_DB_NAME mapping from seed-odds.ts -- extract it into a shared location OR duplicate it in the refresh module (prefer duplication since the seed script is a standalone script, and the mapping is small)
    - Match Odds API event.home_team and event.away_team to DB team names
    - Find fixture by homeTeamId + awayTeamId + status='scheduled' (or upcoming kickoff)

    **Budget awareness:**
    - Log quota remaining after each league fetch
    - If quota remaining drops below 50, log a warning and stop fetching remaining leagues
    - Return quota info in the result object

    **Error handling:**
    - Wrap each league fetch in try/catch -- if one league fails, continue with others
    - Log errors per league, don't abort the whole run

<feature>
  <name>Affiliate Config & Link Builder</name>
  <files>src/lib/affiliate/config.ts, src/lib/affiliate/link-builder.ts, src/lib/affiliate/link-builder.test.ts</files>
  <behavior>
    The link builder is a pure function with these behaviors:

    Config map (src/lib/affiliate/config.ts):
    - Maps bookmaker keys (from The Odds API) to affiliate program metadata
    - Each entry has: programName, trackingParam, envVar, homepage, optional sidTemplate
    - Bookmakers to map: paddypower, coral, ladbrokes_uk, unibet_uk, 888sport, williamhill
    - getAffiliateConfig(key) returns the config or undefined
    - getAffiliateId(config) reads process.env[config.envVar], returns string or undefined

    Link builder (src/lib/affiliate/link-builder.ts):
    - Input: { bookmakerKey: string, apiLink: string | null, sid: string | null }
    - Output: { url: string | null, affiliateProgram: string | null }

    Test cases (input -> expected output):
    1. API link provided, affiliate configured with ID:
       { bookmakerKey: 'paddypower', apiLink: 'https://paddy.com/bet/123', sid: null }
       -> { url: 'https://paddy.com/bet/123?AFF_ID=test123', affiliateProgram: 'paddy_power' }

    2. API link provided, affiliate configured WITHOUT ID (graceful degradation):
       { bookmakerKey: 'paddypower', apiLink: 'https://paddy.com/bet/123', sid: null }
       -> { url: 'https://paddy.com/bet/123', affiliateProgram: 'paddy_power' }

    3. No API link, sid + template available:
       { bookmakerKey: 'paddypower', apiLink: null, sid: 'abc123' }
       -> { url: 'https://www.paddypower.com/bet?sid=abc123?AFF_ID=test123', affiliateProgram: 'paddy_power' }
       (only if sidTemplate configured -- start without sidTemplate, so falls to homepage)

    4. No API link, no sid, homepage fallback:
       { bookmakerKey: 'paddypower', apiLink: null, sid: null }
       -> { url: 'https://www.paddypower.com/football?AFF_ID=test123', affiliateProgram: 'paddy_power' }

    5. Unknown bookmaker with API link:
       { bookmakerKey: 'unknown_bookie', apiLink: 'https://bookie.com/bet/456', sid: null }
       -> { url: 'https://bookie.com/bet/456', affiliateProgram: null }

    6. Unknown bookmaker without API link:
       { bookmakerKey: 'unknown_bookie', apiLink: null, sid: null }
       -> { url: null, affiliateProgram: null }

    7. URL with existing query string (append with &):
       { bookmakerKey: 'coral', apiLink: 'https://coral.co.uk/bet?id=789', sid: null }
       -> { url: 'https://coral.co.uk/bet?id=789&btag=entain123', affiliateProgram: 'entain' }

    8. Multiple bookmakers share same program (coral + ladbrokes_uk both entain):
       Both should use envVar 'ENTAIN_BTAG' and programName 'entain'
  </behavior>

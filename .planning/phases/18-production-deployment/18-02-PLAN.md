<task type="auto">
  <name>Task 1: Deploy to Vercel and apply database migrations</name>
  <files></files>
  <action>
Run the production deployment sequence using CLI tools. This task automates everything possible before the human verification checkpoint.

**Step 1: Check Vercel CLI is available**
```bash
npx vercel --version
```
If not available, install: `npm i -g vercel`

**Step 2: Deploy to Vercel**
```bash
npx vercel --yes
```
This creates a preview deployment. If the user is not authenticated, an auth gate checkpoint will be created dynamically.

After deployment succeeds, capture the deployment URL.

**Step 3: Promote to production**
```bash
npx vercel --prod --yes
```

**Step 4: Apply Drizzle migrations to production database**
The user needs to provide the production DATABASE_URL (from the Neon production project). Once available:
```bash
DATABASE_URL="<production-url>" npx drizzle-kit push
```

**Step 5: Seed production database**
```bash
DATABASE_URL="<production-url>" API_FOOTBALL_KEY="<key>" npm run seed -- --all
```
This seeds all 5 leagues with teams, players, fixtures, standings, and historical data. Uses file cache so API quota is preserved if cache files exist from dev seeding.

**Step 6: Seed odds data**
```bash
DATABASE_URL="<production-url>" ODDS_API_KEY="<key>" npx tsx scripts/seed-odds.ts
```

**Important notes:**
- The Vercel deployment requires env vars to be set in the Vercel dashboard or via `vercel env add`. The env vars from `.env.example` (produced by Plan 18-01) serve as the reference list.
- If the user hasn't created a Neon production database yet, they'll need to do so at console.neon.tech and provide the connection string.
- Seeding all 5 leagues takes significant time and API quota. If running against a fresh API day, it should fit within the 7,500 daily limit.
  </action>
  <verify>
Check deployment URL loads: `curl -s -o /dev/null -w "%{http_code}" <deployment-url>`
Check database has data: `DATABASE_URL="..." npx tsx scripts/verify-db.ts` or `DATABASE_URL="..." npx tsx scripts/check-db.ts`
  </verify>
  <done>Vercel production deployment is live, database migrations applied, and data seeded for all 5 leagues.</done>
</task>

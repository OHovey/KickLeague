Create `src/lib/stats/leaderboard-queries.ts` with three query functions. All queries join `fixtureEvents` -> `fixtures` -> `players` -> `teams`, filtered by league and season, limited to 20 results.

**getTopScorersLeaderboard(leagueId, season, limit=20):**
- Count events where type IN ('goal', 'penalty_scored') and playerId IS NOT NULL
- GROUP BY player, include: playerId, playerName, playerPhotoUrl, teamId, teamName, teamLogoUrl, goalCount
- For appearances: use a subquery or SQL expression counting DISTINCT fixtureId where the player has ANY event (goal, penalty_scored, yellow_card, red_card, substitution, own_goal, penalty_missed, var)
- Calculate goalsPer90 as `(goalCount / appearances) * 90 / 90` -- simplify to `goalCount / appearances` since we're using appearances not minutes. Actually, since we don't have minutes played, calculate as goals per appearance: `ROUND(CAST(goalCount AS DECIMAL) / NULLIF(appearances, 0), 2)`
- ORDER BY goalCount DESC, then goalsPer90 DESC as tiebreaker
- Return type: `LeaderboardScorerRow[]` with fields: playerId, playerName, playerPhotoUrl, teamId, teamName, teamLogoUrl, goals, appearances, goalsPerAppearance

**getTopAssistsLeaderboard(leagueId, season, limit=20):**
- Count events where type IN ('goal', 'penalty_scored') and assistPlayerId IS NOT NULL -- count from assistPlayerId perspective
- GROUP BY assistPlayerId, join to players table on assistPlayerId
- Include: playerId, playerName, playerPhotoUrl, teamId, teamName, teamLogoUrl, assistCount
- Appearances: same subquery pattern as scorers but for the assist player
- Calculate assistsPerAppearance: `ROUND(CAST(assistCount AS DECIMAL) / NULLIF(appearances, 0), 2)`
- ORDER BY assistCount DESC, then assistsPerAppearance DESC as tiebreaker
- Return type: `LeaderboardAssistRow[]`

**getDisciplinaryLeaderboard(leagueId, season, limit=20):**
- Count yellow_card events and red_card events separately for each player
- Use conditional aggregation: `COUNT(CASE WHEN type = 'yellow_card' THEN 1 END)` for yellow cards, same for red cards
- WHERE playerId IS NOT NULL AND type IN ('yellow_card', 'red_card')
- Appearances: same subquery pattern
- ORDER BY (yellowCards + redCards * 2) DESC -- red cards weighted double for sorting, then yellowCards DESC as tiebreaker
- Return type: `LeaderboardDisciplinaryRow[]` with: playerId, playerName, playerPhotoUrl, teamId, teamName, teamLogoUrl, yellowCards, redCards, appearances

Note: Since we don't have a player_fixtures/lineup table, "appearances" means matches where the player had at least one event. This is an approximation -- players who play full matches without any events won't be counted. This is acceptable because these leaderboard players (top scorers, top assist makers, most-carded) by definition have events in their matches. Document this in a code comment.

  <action>
    Create all Drizzle ORM schema files following the patterns and code examples in RESEARCH.md. Key requirements:

    **src/db/schema/enums.ts:**
    Define pgEnum types:
    - `matchStatusEnum`: scheduled, live, finished, postponed, cancelled, first_half, halftime, second_half, extra_time, penalties
    - `eventTypeEnum`: goal, own_goal, penalty_scored, penalty_missed, yellow_card, red_card, substitution, var
    - `tiebreakerMethodEnum`: goal_difference, goals_for, head_to_head, away_goals
    - `zoneTypeEnum`: champions_league, champions_league_qualifying, europa_league, conference_league, relegation_playoff, relegation

    **src/db/schema/leagues.ts:**
    Three tables following RESEARCH.md code example exactly:
    - `leagues`: id (generatedAlwaysAsIdentity), apiId (unique), slug (unique), name, country, logoUrl, currentSeason
    - `league_config`: id, leagueId (FK to leagues, cascade delete), season, teamCount, tiebreakerOrder (comma-separated enum values string), matchweeksTotal, hasXg, hasDetailedStats, hasPlayerStats. Unique on (leagueId, season).
    - `league_zones`: id, leagueId (FK, cascade delete), season, zoneType (pgEnum), startPosition, endPosition, color (hex string). Index on (leagueId, season).

    **src/db/schema/teams.ts:**
    - `teams`: id (generatedAlwaysAsIdentity), apiId (unique), leagueId (FK to leagues), slug (unique), name, shortName, abbreviation (3-letter), logoUrl, stadiumName, founded (integer, nullable), country. Index on leagueId.

    **src/db/schema/players.ts:**
    - `players`: id (generatedAlwaysAsIdentity), apiId (unique), teamId (FK to teams), name, firstName, lastName, position (varchar -- GK/DEF/MID/FWD), number (integer, nullable), nationality, photoUrl, age (integer, nullable), height (varchar, nullable), weight (varchar, nullable). Index on teamId.

    **src/db/schema/fixtures.ts:**
    Three normalized tables following RESEARCH.md exactly:
    - `fixtures`: id, apiId (unique), leagueId (FK), season, matchweek (nullable), homeTeamId (FK), awayTeamId (FK), kickoff (timestamp with timezone), status (matchStatusEnum), homeScore (nullable), awayScore (nullable), referee (nullable), venue (nullable). Indexes on (leagueId, season), kickoff, status, homeTeamId, awayTeamId.
    - `fixture_events`: id, fixtureId (FK, cascade delete), type (eventTypeEnum), minute, extraMinute (nullable), teamId (FK), playerId (FK, nullable), assistPlayerId (FK, nullable), detail (varchar, nullable). Index on fixtureId.
    - `fixture_stats`: id, fixtureId (FK, cascade delete), teamId (FK), possession (real, nullable), shots, shotsOnTarget, corners, fouls, offsides, yellowCards, redCards, xg (real, nullable). All stat columns nullable. Unique on (fixtureId, teamId).

    **src/db/schema/standings.ts:**
    - `standings`: id (generatedAlwaysAsIdentity), leagueId (FK), season, matchweek, teamId (FK), position, played, won, drawn, lost, goalsFor, goalsAgainst, goalDifference, points, form (varchar -- last 5 as "WWDLW" string), homeWon, homeDrawn, homeLost, homeGoalsFor, homeGoalsAgainst, awayWon, awayDrawn, awayLost, awayGoalsFor, awayGoalsAgainst, pointsDeduction (integer, default 0), updatedAt (timestamp). Unique on (leagueId, season, matchweek, teamId). Index on (leagueId, season, matchweek).

    **src/db/schema/relations.ts:**
    Declare ALL Drizzle relation objects:
    - leagues -> many(leagueConfig, leagueZones, teams, fixtures, standings)
    - teams -> one(league), many(players, homeFixtures, awayFixtures, standings)
    - players -> one(team)
    - fixtures -> one(league, homeTeam, awayTeam), many(events, stats)
    - fixtureEvents -> one(fixture, team, player, assistPlayer)
    - fixtureStats -> one(fixture, team)
    - standings -> one(league, team)

    **src/db/schema/index.ts:**
    Barrel export: re-export everything from all schema files (enums, leagues, teams, players, fixtures, standings, relations).

    **Critical constraints from CONTEXT.md and RESEARCH.md:**
    - Use `integer().generatedAlwaysAsIdentity()` for all PKs, NOT serial
    - Every API-mapped table MUST have `apiId` column with unique constraint
    - Events and stats are NORMALIZED tables, NOT JSON blobs
    - Zone definitions are DATA ROWS in league_zones, NOT hardcoded
    - Use proper foreign key references with appropriate cascade rules
  </action>

    - All enum types are properly defined and referenced
    - Schema index.ts barrel export includes all tables and relations
    - If DATABASE_URL is set: `npx drizzle-kit push` creates all tables in Neon (test push)

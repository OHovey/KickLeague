    **src/components/match-detail/actions.ts** -- Server actions for match detail data:

    ```typescript
    'use server';
    ```

    1. `fetchMatchDetail(fixtureId: number)` -- Fetch single fixture with team data:
       - SELECT from fixtures INNER JOIN teams (home alias + away alias) WHERE fixtures.id = fixtureId
       - Return match data with both teams' full info (id, name, shortName, logoUrl)
       - Return null if not found

    2. `fetchMatchStats(fixtureId: number)` -- Fetch stats for both teams:
       - SELECT from fixtureStats WHERE fixtureId
       - Return as `{ home: FixtureStatRow | null, away: FixtureStatRow | null }` (matched by teamId against match homeTeamId/awayTeamId)

    3. `fetchMatchEvents(fixtureId: number)` -- Fetch all events with player names:
       - SELECT from fixtureEvents LEFT JOIN players ON fixtureEvents.playerId = players.id, LEFT JOIN players (assist alias) ON fixtureEvents.assistPlayerId
       - WHERE fixtureId, ORDER BY minute ASC, extraMinute ASC NULLS FIRST
       - Return events with playerName, assistPlayerName, teamId, type, minute, extraMinute, detail

    4. `fetchUpcomingMatchContext(homeTeamId: number, awayTeamId: number, leagueId: number, season: string)` -- Fetch context for upcoming match:
       - Call getH2HSummary(homeTeamId, awayTeamId) for H2H data
       - Query standings for both teams at latest matchweek: position, points, goalsFor, goalsAgainst, form, played, won, drawn, lost
       - Return `{ h2h, homeTeamStats, awayTeamStats }`

    **src/lib/matches/queries.ts** -- Database queries for match lists:

    1. `getRecentMatches(leagueSlug: string, limit: number = 10)` -- Returns recent finished matches:
       - Use `getLeagueBySlug` from `@/lib/standings/queries` to resolve league slug to ID + season
       - Return early with empty array if `!isDatabaseConfigured()` or league not found
       - SELECT from `fixtures` INNER JOIN `teams` twice (use `alias()` from `drizzle-orm/pg-core` for `homeTeam` and `awayTeam`)
       - WHERE `leagueId = league.id AND season = league.currentSeason AND status = 'finished'`
       - ORDER BY `kickoff DESC`
       - LIMIT by `limit` param
       - Select fields: `id, matchweek, kickoff, status, homeScore, awayScore, venue, homeTeam.{id, name, shortName, logoUrl}, awayTeam.{id, name, shortName, logoUrl}`
       - Return type should be an array of a `MatchWithTeams` type (define and export this interface)

    2. `getUpcomingFixtures(leagueSlug: string, limit: number = 10)` -- Returns upcoming scheduled matches:
       - Same pattern as getRecentMatches but WHERE `status = 'scheduled'`
       - ORDER BY `kickoff ASC` (soonest first)

    3. `getKeyEventsForMatches(fixtureIds: number[])` -- Batch fetch key events:
       - SELECT from `fixture_events` INNER JOIN `players` (LEFT JOIN since playerId can be null)
       - WHERE `fixtureId IN (fixtureIds)` AND `type IN ('goal', 'own_goal', 'penalty_scored', 'red_card')`
       - ORDER BY `minute ASC`
       - Return a `Map<number, MatchEvent[]>` keyed by fixtureId for O(1) lookup
       - Use `inArray` from `drizzle-orm` for the IN clause
       - If fixtureIds is empty, return empty Map immediately

    4. `getTeamForm(teamIds: number[], leagueId: number, season: string)` -- Batch fetch form strings:
       - SELECT `teamId, form` from `standings` WHERE teamId IN teamIds AND leagueId AND season AND matchweek = (max matchweek subquery)
       - Return `Map<number, string>` of teamId -> form string (e.g. "WWDLW")
       - This avoids per-card form queries

    **src/lib/matches/h2h.ts** -- Head-to-head queries:

    1. `getH2HMeetings(team1Id: number, team2Id: number, limit: number = 5)` -- Last N meetings:
       - SELECT from `fixtures` WHERE `(homeTeamId = team1 AND awayTeamId = team2) OR vice versa` AND `status = 'finished'`
       - ORDER BY `kickoff DESC`, LIMIT
       - Return array with id, kickoff, homeTeamId, awayTeamId, homeScore, awayScore

    2. `getH2HSummary(team1Id: number, team2Id: number)` -- Summary stats from meetings:
       - Call `getH2HMeetings` with limit 10 (all available)
       - Compute: team1Wins, team2Wins, draws from the meetings
       - Return `{ team1Wins, team2Wins, draws, meetings: H2HMeeting[] }`

    **src/lib/dates/format.ts** -- Client-safe date formatters (no server-side rendering):

    1. `formatKickoffTime(date: Date | string): string` -- "15:00 GMT" format using `Intl.DateTimeFormat(undefined, { hour: '2-digit', minute: '2-digit', timeZoneName: 'short' })`
    2. `formatMatchDate(date: Date | string): string` -- "Saturday 1 February" format using `Intl.DateTimeFormat('en-GB', { weekday: 'long', day: 'numeric', month: 'long' })`
    3. `formatRelativeTime(date: Date | string): string` -- "2 hours ago" for <24h, absolute date for older. Use `Intl.RelativeTimeFormat('en', { numeric: 'auto' })`
    4. `formatMatchDateTime(date: Date | string): string` -- Combined: "Saturday 1 February, 15:00 GMT"

    All functions accept Date or ISO string input and convert internally. Export all functions and all type interfaces.

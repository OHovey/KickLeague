    ```bash
    git remote set-url origin https://github.com/YOUR_USERNAME/KickLeague.git
    ```

  <action>
    **Option A: Rename existing project (if Neon supports it)**
    1. Go to https://console.neon.tech
    2. Select the current project
    3. Go to Settings and rename to "kickleague"
    4. Connection string remains the same -- no env var changes needed

    **Option B: Create new project (if rename not available)**
    1. Create a new Neon project named "kickleague"
    2. Copy the new connection string
    3. Update `DATABASE_URL` in `.env.local` with the new connection string
    4. Run `npx drizzle-kit push` to apply the schema
    5. Run `npx tsx src/lib/seed/index.ts --all` to seed data (uses API-Football daily quota)
    6. Update `DATABASE_URL` in Vercel environment variables (when deploying)

    **Note:** If using Option B, the old Neon project can be kept as a backup until the new one is verified. This operation costs API-Football daily request quota for re-seeding.

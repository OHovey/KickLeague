    With the title.template pattern:
    ```typescript

    export const metadata: Metadata = {
      title: {

      },
      description: 'Football intelligence, visualized',
    };
    ```

    In `src/app/[locale]/matches/[id]/page.tsx`, remove all `| KickData` suffixes from title strings in generateMetadata. The title.template in the layout will auto-append ` | KickLeague`. For example:
    - `'Match Not Found | KickData'` -> `'Match Not Found'`
    - `` `${homeName} ${match.homeScore}-${match.awayScore} ${awayName} | KickData` `` -> `` `${homeName} ${match.homeScore}-${match.awayScore} ${awayName}` ``
    - `'Match | KickData'` -> `'Match'`
    There are 5 occurrences of `| KickData` to remove in this file.

    In `src/app/[locale]/teams/[slug]/page.tsx`, same pattern:
    - `'Team Not Found | KickData'` -> `'Team Not Found'`
    - `` `${team.name} | KickData` `` -> `team.name`
    - `'Team | KickData'` -> `'Team'`
    There are 3 occurrences of `| KickData` to remove.

    **Step 3: Rename remaining source occurrences**

    In `src/components/header/Header.tsx`: Replace the text "KickData" with "KickLeague" in the Link content. (Plan 03 will later replace this with the SVG wordmark.)

    In all 5 message files (`src/messages/{en,es,fr,de,it}.json`): Change `"appName": "KickData"` to `"appName": "KickLeague"`.

    - `console.log(chalk.bold.cyan("\n--- KickData Seed ---"))` -> `console.log(chalk.bold.cyan("\n--- KickLeague Seed ---"))`

    **Step 4: Rename package.json**

    In `package.json`: Change `"name": "kickdata"` to `"name": "kickleague"`.

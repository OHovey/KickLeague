**Budget analysis (why 3-minute polling is safe):**
- Pro tier = 7,500 req/day
- 3-minute intervals = 480 polls/day
- Each poll makes 1 API-Football call per active league (max 5)
- If all 5 leagues have matches simultaneously: 5 * 480 = 2,400 calls/day
- Add daily-resync (5 calls) + refresh-odds (4 * 5 = 20 calls) = 2,425 calls/day
- Well within the 7,500 daily limit (32% utilization)
- Fixture-window detection skips leagues with no active matches, so typical usage will be much lower

**Why 3-minute interval satisfies PIPE-02:** The phase requirement says "polling frequency increases to 3-minute intervals during live matches." With a 3-minute QStash cron, the poll-matches route is called every 3 minutes. The `getActiveLeagues()` function in `fixture-window.ts` already returns early with `no_active_matches` when no fixtures have kickoffs within the +/- 3 hour window, so no API calls are wasted outside match windows. The route only makes API-Football calls when there are active match windows.

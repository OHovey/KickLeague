1. Create `src/lib/hooks/use-matchweek.ts`:
   - Client component hook using nuqs `parseAsInteger` and `useQueryState`.
   - `useMatchweek(latestMatchweek: number)` returns `{ week, setWeek, isHistorical }`.
   - Default value is `latestMatchweek` (when no `?week=` param in URL, shows current standings).
   - `isHistorical` is `week !== latestMatchweek`.
   - Follow the same pattern as the existing `use-league.ts`.

2. Create `src/components/timeline/useAutoPlay.ts`:
   - Client hook: `useAutoPlay(currentWeek, maxWeek, onAdvance, intervalMs = 1000)`.
   - Returns `{ isPlaying, play, pause, toggle }`.
   - Uses `setInterval` in a `useEffect` with proper cleanup (clear on unmount, pause, and league change).
   - Stores interval ID in a `useRef`. Keeps `currentWeek` in a ref to avoid stale closures.
   - Auto-pauses when `currentWeek >= maxWeek` (reached end of completed matchweeks).
   - Follow the pattern from RESEARCH.md code example exactly.

3. Create `src/components/timeline/TimelineCircle.tsx`:
   - Props: `{ weekNumber: number; completed: boolean; isSelected: boolean; isScrubHighlighted: boolean; leagueColor: string; onClick: () => void }`.
   - Renders a circular button, 28px diameter, with:
     - Completed + selected: solid fill in `leagueColor`, white text, slight scale-up (scale-110).
     - Completed + not selected: solid fill in `leagueColor` at 60% opacity, white/70 text.
     - Completed + scrub-highlighted: solid fill in `leagueColor` at 80% opacity (during drag preview).
     - Upcoming (not completed): hollow circle with `leagueColor` border, transparent fill, white/30 text.
   - Disabled state for upcoming weeks (no onClick).
   - Every 5th matchweek AND matchweek 1 AND the last matchweek: show label below the circle.
   - Use `min-w-[28px] min-h-[28px]` for consistent circle sizing.
   - `role="option"` with `aria-selected` for accessibility.

4. Create `src/components/timeline/TimelineStrip.tsx`:
   - Props: `{ matchweeks: Array<{ number: number; completed: boolean }>; selectedWeek: number; latestCompleted: number; leagueColor: string; onSelectWeek: (week: number) => void }`.
   - Renders a horizontally scrollable container (`overflow-x-auto`, `scroll-snap-type: x mandatory`) with all matchweek circles in a flex row.
   - Each circle wrapped with `scroll-snap-align: center` for snap-to-circle scrolling.
   - On initial render and when `selectedWeek` changes, scroll the selected circle into view (use `scrollIntoView({ behavior: 'smooth', inline: 'center' })` via a ref on each circle).
   - Desktop drag-to-scrub: Track `mousedown` -> `mousemove` -> `mouseup` on the strip container. During drag, highlight circles as the cursor passes over them (track via `isScrubHighlighted` state). On `mouseup`, select the last highlighted circle and call `onSelectWeek`. During drag, prevent default click behavior on individual circles.
   - Hide scrollbar with `scrollbar-width: none` and `-webkit-overflow-scrolling: touch`.
   - Mobile: horizontal swipe scrolling is native via overflow-x. Tap on circles handled by individual `onClick`.
   - Add `role="listbox"` with `aria-label="Season matchweeks"` on the container.
   - Support keyboard navigation: when the strip is focused, left/right arrow keys move selection to previous/next completed matchweek.

5. Create `src/components/timeline/TimelineControls.tsx`:
   - Props: `{ isPlaying: boolean; onToggle: () => void; isAtEnd: boolean }`.
   - Renders a play/pause button with appropriate icon (play triangle / pause bars SVG).
   - When `isAtEnd` and not playing, show a replay icon (circular arrow) instead of play.
   - Styled as a small circular button (36px) with `bg-white/10 hover:bg-white/20` matching the site theme.
   - `aria-label` toggles between "Play season timeline" / "Pause season timeline" / "Replay season timeline".

6. Create `src/components/timeline/SeasonTimeline.tsx`:
   - The main orchestrating component. Props: `{ league: string; latestMatchweek: number; matchweeks: Array<{ number: number; completed: boolean }>; leagueColor: string; selectedWeek: number; onWeekChange: (week: number) => void }`.
   - Renders `TimelineControls` on the left, `TimelineStrip` filling the remaining width on the right, in a flex row.
   - Connects `useAutoPlay` hook: `onAdvance` calls `onWeekChange`. Auto-play pauses when user manually selects a week.
   - Client-side matchweek data cache: Maintain a `Map<number, StandingsData>` in the parent (LeagueTableWrapper or LeagueTableClient) to cache fetched standings by matchweek. When switching to a previously-visited matchweek, use cached data immediately instead of re-fetching. This cache is managed by the parent, not by SeasonTimeline itself -- SeasonTimeline only controls which week is selected.
   - Add a subtle bottom border (`border-b border-white/10`) to visually separate timeline from the table below.

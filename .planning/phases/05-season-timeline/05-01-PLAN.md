<objective>
Add matchweek-parameterized historical standings queries and convert the league table from HTML `<table>` elements to a CSS Grid `<div>` layout with Motion layout animations and NumberFlow stat counters.

Purpose: The current `<table>`-based layout cannot support CSS `transform` for row reorder animations (MDN spec: transform unreliable on table-row display elements). Converting to `<div>` grid with Motion's `layout` prop enables the smooth staggered row animations required for the season timeline feature. The matchweek-parameterized queries provide the data backbone for historical standings retrieval.

Output: Matchweek-aware standings queries and server actions, a fully refactored div-based league table that renders identically to the current table but supports animated row reordering and digit-spin stat transitions.
</objective>

1. Create `src/components/league-table/AnimatedStatCell.tsx`:
   - A client component that wraps `NumberFlow` from `@number-flow/react`.
   - Props: `{ value: number; className?: string }`.
   - Renders `<NumberFlow value={value} transformTiming={{ duration: 300, easing: 'ease-out' }} spinTiming={{ duration: 300, easing: 'ease-out' }} trend={0} />`.
   - Use `trend={0}` so digits find shortest path (no forced up/down direction).
   - Apply the className to the wrapper for consistent styling with existing table cells.

2. Create `src/components/league-table/AnimatedTableRow.tsx`:
   - A client component using `motion.div` from `motion/react` with `layout="position"`.
   - Props: `{ row: EnhancedStandingsRow; index: number; zoneColor: string | null }`.
   - Use `layout="position"` (NOT `layout` or `layout={true}`) to avoid child distortion.
   - Transition config: `{ layout: { type: "spring", stiffness: 500, damping: 35, mass: 0.8, delay: index * 0.015 } }` -- creates ~300ms cascading stagger for 20 teams.
   - Render as a CSS Grid row using the EXACT same grid template and column classes as the existing `<tr>` in TableRow.tsx. The grid template must match the header in LeagueTableClient.tsx.
   - Grid columns: `grid-cols-[2.5rem_1fr_2.5rem_2.5rem_2.5rem_2.5rem_2.5rem_2.5rem_3rem_3rem_auto_auto_auto_2rem]` for desktop (14 columns: #, Team, P, W, D, L, GF, GA, GD, Pts, Form, +/-, Trend, mobile-expand). On mobile, hide W/D/L/GF/GA columns with `hidden md:block`.
   - Use `AnimatedStatCell` for all numeric stat values (position, played, won, drawn, lost, goalsFor, goalsAgainst, goalDifference, points).
   - Include the zone color indicator (absolute left border div), team name as `<Link>` to `/teams/{slug}`, `FormBadges`, `PositionChange`, `Sparkline` (all desktop-only).
   - Include mobile expand indicator chevron and expand/collapse behavior for mobile (same as existing TableRow).
   - Use `role="row"` on the outer div, `role="cell"` on each cell div for accessibility.
   - CRITICAL: Use `key={row.teamId}` -- never `key={index}` or `key={row.position}`. The key must be the stable team identifier for Motion to track row identity across reorders.
   - Wrap with `React.memo` to prevent unnecessary re-renders that could disrupt layout animation tracking.

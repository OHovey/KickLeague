<feature>
  <name>Bookmaker Availability Config and Filtering</name>
  <files>src/lib/geo/bookmaker-availability.ts, src/lib/geo/bookmaker-availability.test.ts</files>
  <behavior>
    The module provides two exported functions:

    1. `getAvailableBookmakers(countryCode: string | null): BookmakerEntry[]`
       - Returns array of `{ bookmakerKey: string, priority: number }` sorted by priority ASC then alphabetically by key for ties
       - Country code is case-insensitive (always uppercased internally)
       - null or unknown country code returns GB default (all 8 bookmakers)

    2. `isCountryMapped(countryCode: string | null): boolean`
       - Returns true if the country has an explicit entry in the config
       - Returns false for null or unknown codes
       - Used to determine whether to show the "Showing bookmakers for your region" fallback note

    Country-bookmaker matrix (from RESEARCH.md):
    - GB: all 8 -- paddypower(1), williamhill(2), coral(3), ladbrokes_uk(4), skybet(5), unibet_uk(6), sport888(7), betfair_sb_uk(8)
    - DK: betfair_sb_uk(1), unibet_uk(2)
    - SE: unibet_uk(1), williamhill(2), coral(3), ladbrokes_uk(4), betfair_sb_uk(5)
    - FR: unibet_uk(1)
    - PT: betfair_sb_uk(1)
    - AT: unibet_uk(1), williamhill(2), sport888(3), betfair_sb_uk(4)
    - CH: unibet_uk(1), williamhill(2), sport888(3), betfair_sb_uk(4)
    - DE: williamhill(1), betfair_sb_uk(2)

    Also export the `BookmakerEntry` interface and the `BOOKMAKER_AVAILABILITY` const for direct access if needed.

    Cases:
    - getAvailableBookmakers('GB') -> 8 entries, paddypower first
    - getAvailableBookmakers('FR') -> [{ bookmakerKey: 'unibet_uk', priority: 1 }]
    - getAvailableBookmakers('gb') -> same as 'GB' (case insensitive)
    - getAvailableBookmakers(null) -> GB default (8 entries)
    - getAvailableBookmakers('ZZ') -> GB default (8 entries)
    - getAvailableBookmakers('DK') -> 2 entries, betfair_sb_uk first
    - isCountryMapped('GB') -> true
    - isCountryMapped('ZZ') -> false
    - isCountryMapped(null) -> false
    - isCountryMapped('gb') -> true (case insensitive)
  </behavior>
  <implementation>
    Use a `Record<string, BookmakerEntry[]>` const for the availability map.
    Store entries already sorted by priority in the config to avoid runtime sorting overhead.
    The `getAvailableBookmakers` function uppercases the input, looks up in the map, falls back to GB.
    No external dependencies -- pure TypeScript logic.

    Use vitest (the project's test runner per the existing test file at src/lib/affiliate/link-builder.test.ts).
  </implementation>
</feature>

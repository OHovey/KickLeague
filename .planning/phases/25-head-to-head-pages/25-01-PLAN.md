Create `src/lib/h2h/queries.ts` with raw SQL queries (same pattern as player queries using `db.execute(sql)`):

**Types to define:**
- `H2HMeeting`: fixtureId, kickoff (string), matchweek (number|null), venue (string|null), homeTeamId, homeTeamName, homeTeamSlug, homeTeamLogoUrl, awayTeamId, awayTeamName, awayTeamSlug, awayTeamLogoUrl, homeScore (number|null), awayScore (number|null)
- `H2HAggregateRecord`: team1Wins, team2Wins, draws, team1Goals, team2Goals, totalMeetings
- `TeamFormAndPosition`: teamId, teamName, teamSlug, teamLogoUrl, leagueSlug, leagueName, position, played, points, form (string|null -- last 5 as "WWDLW")
- `H2HTeamPair`: team1Slug, team2Slug (for sitemap/static params)

**Queries to implement:**

1. `getH2HMeetings(team1Slug: string, team2Slug: string)`: Query fixtures where (home_team_id = team1 AND away_team_id = team2) OR (home_team_id = team2 AND away_team_id = team1), joining teams for names/logos/slugs. Filter to finished matches only. Order by kickoff DESC. Return H2HMeeting[].

2. `getH2HAggregateRecord(meetings: H2HMeeting[], team1Id: number, team2Id: number)`: Pure function (no DB query). Iterate meetings to compute wins for each side, draws, and total goals. The team1/team2 designation follows the order from the URL slug (first team listed = team1).

3. `getTeamFormAndPosition(teamSlug: string)`: Query the latest standings row for this team (max matchweek in current season), joining teams and leagues for context. Return TeamFormAndPosition with position, played, points, and form string. Uses existing standings table pattern from getTeamCurrentStandings.

4. `getQualifyingH2HPairs()`: Query all team pairs where COUNT(fixtures between them with status='finished') >= 3. This includes both directions (home/away swapped). Return H2HTeamPair[] with slugs sorted alphabetically (so arsenal-vs-chelsea and chelsea-vs-arsenal resolve to the same canonical pair). Use raw SQL:
   ```sql
   SELECT t1.slug AS team1_slug, t2.slug AS team2_slug
   FROM fixtures f
   INNER JOIN teams t1 ON LEAST(f.home_team_id, f.away_team_id) = t1.id
   INNER JOIN teams t2 ON GREATEST(f.home_team_id, f.away_team_id) = t2.id
   WHERE f.status = 'finished'
   GROUP BY t1.slug, t2.slug
   HAVING COUNT(*) >= 3
   ORDER BY t1.slug, t2.slug
   ```
   Note: LEAST/GREATEST ensures each pair is counted once regardless of home/away order. The slug in the URL should be `{alphabetically-first-slug}-vs-{second-slug}` for canonical consistency.

Create `src/components/h2h-page/actions.ts` as a `'use server'` module:

**fetchH2HPageData(matchupSlug: string)** server action:
1. Check isDatabaseConfigured() -- return null if not
2. Parse matchupSlug by splitting on `-vs-` to get two team slug fragments. The matchup slug format is `{team1slug}-vs-{team2slug}`. Use a regex or find the `-vs-` separator. Handle edge cases: team slugs might contain hyphens (e.g., "manchester-united-vs-manchester-city").

   Strategy for parsing: Query ALL team slugs from DB, then find which combination of splitting the matchupSlug on `-vs-` yields two valid team slugs. This avoids ambiguity with hyphens in team names. Example: for "manchester-united-vs-manchester-city", try each position of "-vs-" and check if both sides are valid slugs.

3. Look up both teams from DB (using getTeamBySlug pattern from teams/queries.ts)
4. Call getH2HMeetings to get all meetings
5. Apply thin content guard: if meetings.length < 3, return null (triggers 404)
6. Compute aggregate record from meetings
7. Call getTeamFormAndPosition for both teams in parallel
8. Localize team names (follow pattern from league-page/actions.ts with getLocalizedTeamNames)
9. Return typed H2HPageData object

**Do NOT re-export types from the 'use server' module** (Next.js 16 Turbopack strips type exports from server action modules). Define types in queries.ts and import directly in page.tsx.

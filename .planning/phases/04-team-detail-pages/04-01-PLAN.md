  <action>
    **Create `src/lib/teams/queries.ts`** with the following query functions:

    1. **`getTeamBySlug(slug: string)`** - Fetches a team by slug, joining with leagues table to get leagueSlug, leagueName, currentSeason. Returns `{ id, apiId, name, shortName, slug, logoUrl, stadiumName, leagueId, leagueSlug, leagueName, currentSeason }` or null.

    2. **`getTeamCurrentStandings(teamId: number, leagueId: number, season: string)`** - Fetches the latest matchweek standings row for a specific team. Finds max matchweek first, then fetches that row. Returns `{ position, played, won, drawn, lost, goalsFor, goalsAgainst, goalDifference, points, form, homeWon, homeDrawn, homeLost, homeGoalsFor, homeGoalsAgainst, awayWon, awayDrawn, awayLost, awayGoalsFor, awayGoalsAgainst }` or null.

    3. **`getPositionHistory(leagueId: number, season: string, teamIds: number[])`** - Fetches ALL matchweek positions for given teamIds. Joins standings with teams to get team names. Returns data shaped for the bump chart: `Array<{ matchweek: number; [teamName: string]: number }>`. Transform rows by pivoting: group by matchweek, each entry has matchweek + team name keys with position values.

    4. **`getCumulativePoints(teamId: number, leagueId: number, season: string)`** - Fetches all matchweek standings for the team, ordered by matchweek asc. Returns `Array<{ matchweek: number; points: number }>` (already cumulative in standings table).

    5. **`getRivalTeamIds(teamId: number, leagueId: number, season: string, range: number = 3)`** - Finds teams within +/- `range` positions of the focus team at the latest matchweek. Returns array of team IDs (excluding the focus team). Used to determine which rivals to show on the bump chart.

    Use imports from `@/db/schema` and `@/db/connection`. Follow existing patterns: `getDb()`, Drizzle `eq`, `and`, `asc`, `desc`, `max`, `inArray`, `gte`, `lte` from drizzle-orm. Use `isDatabaseConfigured()` guard at start of each function.

    **Create `src/components/team-detail/actions.ts`** with `'use server'` directive:

    1. **`fetchTeamBySlug(slug: string)`** - Calls `getTeamBySlug`, returns the result. Also fetches `getTeamCurrentStandings` and `getLeagueConfig` to bundle hero data. Returns a `TeamPageData` type with team info + current standings + league config flags.

    2. **Stub server actions** for tabs (implemented in 04-02 and 04-03):
       - `fetchOverviewData(teamId: number, leagueId: number, season: string)` - Returns `{ positionHistory, cumulativePoints, form, seasonSummary }`. For now, implement position history (calls `getRivalTeamIds` then `getPositionHistory`) and cumulative points (calls `getCumulativePoints`). Season summary derived from current standings.
       - `fetchPerformanceData(teamId: number, leagueId: number, season: string)` - Stub returning `null` (filled in 04-02).
       - `fetchSquadData(teamId: number, leagueId: number, season: string)` - Stub returning `null` (filled in 04-03).
       - `fetchFixturesData(teamId: number, leagueId: number, season: string)` - Stub returning `null` (filled in 04-03).

    Export all types needed by components (TeamPageData, OverviewData, etc.).
  </action>

  </verify>

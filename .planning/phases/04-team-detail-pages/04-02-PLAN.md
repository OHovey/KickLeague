    **Extend `src/lib/teams/queries.ts`** with new query functions needed for the performance tab (building them now so both tabs' queries are in one commit):

    1. **`getGoalsByPeriod(teamId, leagueId, season)`** - Fetches all goal events (type IN 'goal', 'own_goal', 'penalty_scored') from fixtures involving the team. Buckets them into 6 periods using `Math.min(Math.floor((minute - 1) / 15), 5)` where periods are '0-15', '16-30', '31-45', '46-60', '61-75', '76-90+'. For each period, counts goals scored by the team vs conceded. Own goals: if own_goal teamId matches our team, it counts as conceded by us (opponent benefits). Returns `Array<{ period: string; scored: number; conceded: number }>`.

    2. **`getCumulativeXg(teamId, leagueId, season)`** - Fetches fixtureStats.xg for the team joined with fixtures ordered by matchweek. Computes cumulative xG and cumulative actual goals (from fixture scores). Returns `Array<{ matchweek: number; cumulativeXg: number; cumulativeGoals: number }>`. Handle null xg values gracefully.

    3. **`getCleanSheets(teamId, leagueId, season)`** - Counts fixtures where the team conceded 0 goals. A clean sheet = when team is home and awayScore === 0, or team is away and homeScore === 0. Returns `{ cleanSheets: number; totalMatches: number }`.

    4. **`getScoringFirstRecord(teamId, leagueId, season)`** - For each finished fixture involving the team: find the earliest goal event (MIN minute). Determine if the team scored first (event teamId matches and type is goal/penalty_scored) or conceded first (event teamId is opponent). Then check fixture final result (win/draw/loss for the team). Return `{ scoredFirst: { wins: number; draws: number; losses: number; total: number }; concededFirst: { wins: number; draws: number; losses: number; total: number }; noGoals: number }`. Handle own goals: an own_goal by our team means the opponent scored first. Handle 0-0 draws separately in noGoals.

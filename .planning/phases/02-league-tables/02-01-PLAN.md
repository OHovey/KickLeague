<feature>
  <name>Standings Calculator with Tiebreakers</name>
  <files>src/lib/standings/calculate.ts, src/lib/standings/calculate.test.ts</files>
  <behavior>
    Given standings rows with equal points, apply tiebreaker chain:

    **Test Cases:**
    1. GD tiebreaker: Team A (40pts, +15 GD) vs Team B (40pts, +10 GD) -> A ranks higher
    2. H2H tiebreaker: Team A beat Team B in both matches -> A ranks higher when tied on points
    3. Goals scored tiebreaker: Equal points, equal GD -> team with more GF ranks higher
    4. Multi-way tie (3+ teams): Apply H2H among tied teams, then fall through to GD
    5. Chain exhaustion: When all tiebreakers equal, sort alphabetically by team name

    **Tiebreaker chains:**
    - Premier League: [goal_difference, goals_for, head_to_head]
    - La Liga: [head_to_head, goal_difference, goals_for]
    - Serie A: [head_to_head, goal_difference, goals_for]
    - Bundesliga: [goal_difference, goals_for, head_to_head]
    - Ligue 1: [goal_difference, goals_for, head_to_head]
  </behavior>
  <implementation>
    1. Install Vitest: `npm install -D vitest @vitest/ui`
    2. Create vitest.config.ts with TypeScript support
    3. Add "test" script to package.json
    4. Create src/lib/standings/calculate.ts with:
       - `StandingsRow` type matching DB schema
       - `TiebreakerMethod` type: 'goal_difference' | 'goals_for' | 'head_to_head'
       - `applyTiebreakers(rows, chain, h2hMatrix?)` - sorts rows using chain
       - `calculateStandings(rows, config, fixtures?)` - full calculation
    5. H2H calculation: Build matrix from fixtures when needed, compare points between tied teams
    6. Return sorted rows with position field updated
  </implementation>
</feature>

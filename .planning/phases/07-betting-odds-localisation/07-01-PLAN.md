Create `src/lib/odds-api/types.ts`:
- Define Zod schemas for The Odds API v4 response:
  - `oddsOutcomeSchema`: { name: string, price: number, link: string (optional), sid: string (optional) }

  - `oddsBookmakerSchema`: { key: string, title: string, last_update: string, markets: array of markets }
  - `oddsEventSchema`: { id: string, sport_key: string, sport_title: string, commence_time: string, home_team: string, away_team: string, bookmakers: array of bookmakers }
  - `oddsApiResponseSchema`: array of oddsEventSchema
- Use Zod v4 with the partial-accept pattern established in 01-02: safeParse always, passthrough on objects, nullable/optional liberally.
- Export inferred TypeScript types alongside schemas.

Create `src/lib/odds-api/sport-keys.ts`:
- Export `SPORT_KEY_MAP`: Record mapping internal league slugs to Odds API sport keys:
  - `'premier-league'` -> `'soccer_epl'`
  - `'la-liga'` -> `'soccer_spain_la_liga'`
  - `'bundesliga'` -> `'soccer_germany_bundesliga'`
  - `'serie-a'` -> `'soccer_italy_serie_a'`
  - `'ligue-1'` -> `'soccer_france_ligue_one'`
- Export `getSportKey(leagueSlug: string): string | undefined` helper.

Create `src/lib/odds-api/client.ts`:
- Follow the pattern from `src/lib/api-football/client.ts` (class-based or function-based, match what exists).
- `fetchOddsForSport(sportKey: string, options?: { regions?: string, markets?: string, eventIds?: string[] })`:
  - Base URL: `https://api.the-odds-api.com`
  - Endpoint: `/v4/sports/${sportKey}/odds`
  - Required params: apiKey (from `process.env.ODDS_API_KEY`), regions (default 'eu,uk'), markets (default 'h2h'), oddsFormat='decimal', dateFormat='iso', includeLinks='true', includeSids='true'
  - Optional: eventIds (comma-joined)
  - Parse response with `oddsApiResponseSchema.safeParse()` using partial-accept pattern
  - Extract quota from response headers: `x-requests-remaining`, `x-requests-used`, `x-requests-last`
  - Return `{ data: OddsEvent[], quota: { remaining: number, used: number, lastCost: number } }`
  - Throw on non-OK response with status code
- `fetchSportsKeys()`: GET `/v4/sports` to discover available sport keys. This costs 0 credits.

Create `src/lib/odds-api/odds-format.ts`:
- `decimalToAmerican(decimal: number): string` -- returns "+150" or "-200" format
  - If decimal >= 2.0: `+${Math.round((decimal - 1) * 100)}`
  - If decimal < 2.0: `${Math.round(-100 / (decimal - 1))}`
- `decimalToFractional(decimal: number): string` -- returns "3/2" format
  - Common fractions lookup table for standard values (1/10, 1/5, 1/4, 1/3, 1/2, 2/3, 1/1, 6/5, 5/4, 11/8, 6/4, 13/8, 7/4, 15/8, 2/1, 9/4, 5/2, 11/4, 3/1, 7/2, 4/1, 9/2, 5/1, 6/1, 7/1, 8/1, 9/1, 10/1)
  - GCD-based simplification fallback for non-standard values
- `formatOdds(decimal: number, format: 'decimal' | 'fractional' | 'american'): string`
  - decimal: return `decimal.toFixed(2)`
  - fractional: return `decimalToFractional(decimal)`
  - american: return `decimalToAmerican(decimal)`

Create `src/lib/odds-api/odds-format.test.ts`:

- Test `formatOdds` with all three formats for a sample value

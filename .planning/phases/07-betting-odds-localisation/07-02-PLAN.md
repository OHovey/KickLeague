Create `src/components/odds/actions.ts` (server actions):
- `fetchOddsForFixture(fixtureId: number)`:
  - Query fixture_odds table for given fixtureId
  - Return array of `{ bookmakerKey, bookmakerTitle, homeOdds, drawOdds, awayOdds, homeLink, drawLink, awayLink, prevHomeOdds, prevDrawOdds, prevAwayOdds, lastUpdated }`
  - Sort by best home odds descending (best odds first)
  - Include `fetchedAt` timestamp for "last updated" display
- `fetchCompactOdds(fixtureIds: number[])`:
  - For each fixture, find the BEST odds per outcome across all bookmakers
  - Return Map<fixtureId, { bestHome, bestDraw, bestAway, bookmakerCount }>
  - This powers the compact badge on fixture cards

Create `src/components/odds/OddsFormatSwitcher.tsx`:
- 'use client' component
- Three-option toggle: Decimal | Fractional | American
- Store preference in localStorage key 'odds-format' (default: 'decimal')
- Use Zustand store or simple useState + localStorage for persistence across components
- Expose current format via React context or prop drilling
- Styled as pill toggle matching site dark theme

Create `src/components/odds/OddsCell.tsx`:
- 'use client' component
- Props: `{ value: number, link: string | null, format: 'decimal' | 'fractional' | 'american', prevValue: number | null, fixtureId: number, bookmakerKey: string, outcome: 'home' | 'draw' | 'away' }`
- Display formatted odds value using `formatOdds(value, format)` from odds-format.ts
- Movement indicator:
  - If prevValue exists and differs from value:
    - value > prevValue (odds drifted/lengthened): small up arrow, subtle green tint
    - value < prevValue (odds shortened): small down arrow, subtle red tint
  - If no prevValue or same: no indicator
- Click behavior:
  - Fire-and-forget POST to `/api/clicks` with `{ fixtureId, bookmakerKey, outcome, odds: value }`
  - If link exists: `window.open(link, '_blank', 'noopener')` to open bookmaker in new tab
  - If no link: just track the click (no navigation)
- Style: monospace font for odds value, hover highlight, cursor pointer when link exists

Create `src/components/odds/OddsComparisonTable.tsx`:
- 'use client' component
- Props: `{ fixtureId: number, homeTeam: string, awayTeam: string, showBetting: boolean }`
- If !showBetting: render null (geo-blocked)
- On mount: call fetchOddsForFixture server action
- Loading state: skeleton with 3 columns
- Empty state: translated "Odds not available" message
- Layout: Oddschecker-style comparison table
  - Header row: Bookmaker | Home (team name) | Draw | Away (team name)
  - One row per bookmaker: bookmaker title, then 3 OddsCell components
  - Highlight best odds per outcome column with subtle background
  - OddsFormatSwitcher above the table
- "Last updated" timestamp below table (relative time from fetchedAt)
- ResponsibleGambling component at the bottom

Create `src/components/odds/CompactOdds.tsx`:
- 'use client' component
- Props: `{ fixtureId: number, bestHome: number, bestDraw: number, bestAway: number, bookmakerCount: number, showBetting: boolean }`
- If !showBetting: render null
- Compact horizontal display: "1.85 | 3.40 | 4.20" with "from 5 bookmakers" badge
- Clickable -- links to the match detail page where full comparison lives
- Styled to fit inside MatchCard without expanding it

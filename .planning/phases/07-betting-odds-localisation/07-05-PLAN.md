  <name>Task 1: Team translations schema and resolution helper</name>
  <files>src/db/schema/translations.ts, src/db/schema/index.ts, src/lib/teams/translations.ts</files>
  <action>
Create `src/db/schema/translations.ts`:
- `teamTranslations` table (`team_translations`):
  - `id`: integer, primary key, generated always as identity
  - `teamId`: integer, NOT NULL, references teams.id with onDelete cascade
  - `locale`: varchar(5), NOT NULL (e.g., 'en', 'es', 'de', 'it', 'fr')
  - `name`: varchar(200), NOT NULL (translated team name)
  - Unique index on (teamId, locale)
  - Index on locale

Follow exact patterns from existing schema files (import style, table definition).

Add `export * from './translations';` to `src/db/schema/index.ts`.

Create `src/lib/teams/translations.ts`:
- `getTeamTranslations(teamIds: number[], locale: string): Promise<Map<number, string>>`
  - Query team_translations table for given teamIds and locale
  - Return Map<teamId, translatedName>
  - For teams without a translation row, they simply won't be in the map (caller uses English fallback)

- `getTeamName(teamId: number, englishName: string, translationsMap: Map<number, string>): string`
  - Pure function: returns `translationsMap.get(teamId) ?? englishName`
  - This is the fallback logic -- always returns a name, never undefined

- `getLocalizedTeamNames(teamIds: number[], locale: string, englishNames: Map<number, string>): Promise<Map<number, string>>`
  - Convenience function that combines getTeamTranslations + fallback for a batch of teams
  - If locale is 'en', skip the query entirely and return englishNames directly
  - Otherwise, fetch translations and merge with English fallbacks

The translation table starts empty. Translations will be populated manually or via a future seed script. The key design: when a translation doesn't exist, the English name displays. No errors, no missing text.
  </action>
  <verify>Run `npx tsc --noEmit` -- no type errors. Verify exports: `grep teamTranslations src/db/schema/index.ts`.</verify>
  <done>team_translations table defined with (teamId, locale) unique constraint. Translation helper resolves locale-specific names with English fallback. Schema barrel export updated.</done>

# Plan 08-01: Thread showBetting Through TeamTabs to FixturesTab

## Objective

Fix the audit gap where `TeamTabs` does not pass `showBetting` to `FixturesTab`, causing betting odds to be hidden on team fixture pages for ALL users (including non-restricted countries).

## Root Cause

`TeamTabs.tsx` renders `<FixturesTab>` without a `showBetting` prop. `FixturesTab` defaults `showBetting` to `false`, so odds are never fetched or displayed regardless of the user's geo-location.

The identical pattern was already implemented in `MatchListClient.tsx` (commit `6dc00d9`) but was not applied to the team detail page.

## Reference Pattern

From `src/components/matches/MatchListClient.tsx` (lines 57, 100-102, 157):

```tsx
const [showBetting, setShowBetting] = useState(false);

useEffect(() => {
  getShowBetting().then(setShowBetting);
}, []);

// Later:
<MatchList ... showBetting={showBetting} />
```

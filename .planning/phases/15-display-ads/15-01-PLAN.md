  <action>
**ad-config.ts:**
Create a configuration module exporting:
- `ADSENSE_PUBLISHER_ID`: reads from `process.env.NEXT_PUBLIC_ADSENSE_PUBLISHER_ID` with empty string fallback (component renders nothing if not configured)
- `AD_SLOTS` object with named slot configs. Each slot has a `slotId` (string placeholder -- user fills with real AdSense slot IDs) and `format` ('auto'). Define slots: `HOMEPAGE_TOP`, `HOMEPAGE_BOTTOM`, `MATCHES_TOP`, `MATCHES_BOTTOM`, `MATCH_DETAIL_1`, `MATCH_DETAIL_2`, `TEAM_DETAIL_1`, `TEAM_DETAIL_2`. Each slot's `slotId` should read from a corresponding env var (e.g., `process.env.NEXT_PUBLIC_AD_SLOT_HOMEPAGE_TOP`) with empty string fallback.

**AdUnit.tsx:**
Create a `'use client'` component with these responsibilities:

1. **Props:** `slotId: string`, `format?: string` (default 'auto'), `className?: string`
2. **Early return:** If `ADSENSE_PUBLISHER_ID` is empty or `slotId` is empty, render nothing (return `null`). This handles the case where AdSense is not configured.
3. **State:** `adStatus` state: `'loading' | 'loaded' | 'blocked' | 'unfilled'`, initial `'loading'`
4. **Script loading:** On mount, check if the `adsbygoogle.js` script is already in the DOM (query `script[src*="adsbygoogle"]`). If not, create a `<script>` element with `src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=${ADSENSE_PUBLISHER_ID}"`, `async`, `crossOrigin="anonymous"`. Append to `document.head`. Attach `onload` and `onerror` handlers. On error, set `adStatus` to `'blocked'`. Use a module-level `let scriptPromise: Promise<void> | null = null` to ensure only one script load attempt across all AdUnit instances.
5. **IntersectionObserver lazy trigger:** Use a `ref` on the wrapper div. Create an IntersectionObserver with `rootMargin: '200px'` (load when 200px from viewport). When intersecting AND script loaded successfully, call `(window.adsbygoogle = window.adsbygoogle || []).push({})`. Disconnect observer after push. If script failed, set `'blocked'`.
6. **Unfilled detection:** After pushing, set a 3-second timeout. If the `<ins>` element's `data-ad-status` attribute is `'unfilled'` after 3s, set state to `'unfilled'`.
7. **Route change handling:** Use `usePathname()` from `next/navigation` as part of the `key` prop on the `<ins>` element so React remounts it on client-side navigation.
8. **Render:**
   - If `adStatus === 'blocked'` or `adStatus === 'unfilled'`: render nothing (`null`) -- graceful collapse per user decision.
   - If `adStatus === 'loading'`: render the skeleton placeholder inside the wrapper.
   - Always render a wrapper `<div>` with `ref` for IntersectionObserver:
     - Wrapper classes: `rounded-xl border border-white/5 bg-white/[0.02] overflow-hidden` (glass container per discretion)
     - Inside: a subtle "Ad" label: `<span className="block text-[10px] text-white/20 uppercase tracking-widest text-center pt-2">Ad</span>`
     - The skeleton: a `<div>` with `min-h-[100px] animate-pulse bg-white/[0.03] rounded-lg m-2` that shows during loading state
     - The `<ins className="adsbygoogle" style={{ display: 'block' }} data-ad-client={ADSENSE_PUBLISHER_ID} data-ad-slot={slotId} data-ad-format={format} data-full-width-responsive="true" key={pathname} />`
   - Pass through `className` on the outermost wrapper for spacing control.

**TypeScript:** Add `adsbygoogle` to the global Window interface via a module-level `declare global { interface Window { adsbygoogle: Array<Record<string, unknown>>; } }`.

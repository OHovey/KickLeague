  <name>Task 1: Create stat highlight database queries</name>
  <files>src/lib/stats/queries.ts</files>
  <action>
    Create `src/lib/stats/queries.ts` with three exported query functions. Follow the existing query patterns from `src/lib/standings/queries.ts` and `src/lib/matches/queries.ts`.

    **getTopScorer(leagueId: number, season: string):**
    - Query `fixtureEvents` joined with `fixtures`, `players`, and `teams`
    - Filter: `fixtures.leagueId = leagueId`, `fixtures.season = season`, event type IN ('goal', 'penalty_scored')
    - Exclude `own_goal` (own goals should NOT count toward a player's tally)
    - Group by player, count goals
    - Order by goal count descending, limit 1
    - Return: `{ playerId, playerName, teamName, teamLogoUrl, goalCount } | null`
    - Note: `players.teamId` references `teams.id`, so join players -> teams for team info
    - Handle case where `fixtureEvents.playerId` might be null (skip those events with a WHERE clause)

    **getBiggestUpset(leagueId: number, season: string):**
    - Use odds-based approach (per user discretion recommendation in RESEARCH.md)
    - Query `fixtures` joined with `fixtureOdds` and `teams` (for both home and away)
    - Filter: `fixtures.leagueId = leagueId`, `fixtures.season = season`, `fixtures.status = 'finished'`, `homeScore != awayScore` (no draws)
    - Group by fixture, compute average home odds and average away odds across bookmakers
    - The upset magnitude is the winning team's average odds (higher = bigger upset)
    - Use a CASE expression: when homeScore > awayScore then avgHomeOdds, else avgAwayOdds
    - Order by upset magnitude descending, limit 1
    - After getting the top fixture, enrich with team names and logos by joining teams table for both homeTeamId and awayTeamId
    - Return: `{ fixtureId, homeTeamName, homeTeamLogoUrl, awayTeamName, awayTeamLogoUrl, homeScore, awayScore, matchweek, winningOdds } | null`
    - Note: Use aliased self-joins on `teams` for home team and away team: `const homeTeam = aliasedTable(teams, 'home_team')` and `const awayTeam = aliasedTable(teams, 'away_team')` -- or do two separate queries if alias complexity is too high. Alternatively, do the main query for the fixture, then fetch team details separately.

    **getFormTeam(leagueId: number, season: string):**
    - Query `standings` joined with `teams`
    - First get the max matchweek for this league+season
    - Then get all teams' form at that matchweek
    - Score form using SQL: W=3, D=1, L=0 via `LENGTH(form) - LENGTH(REPLACE(form, 'W', ''))` counting
    - Order by form score descending, limit 1
    - Return: `{ teamId, teamName, teamLogoUrl, form, position, points } | null`

    **Type exports:**
    - Export TypeScript interfaces for each return type: `TopScorerResult`, `BiggestUpsetResult`, `FormTeamResult`
    - All return types use plain serializable values (no Date objects, no Maps)
  </action>

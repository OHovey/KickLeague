1. **Add slug column to players schema** (`src/db/schema/players.ts`):
   - Add `slug: varchar('slug', { length: 150 }).notNull().unique()` to the players table
   - Add an index on slug: `index('players_slug_idx').on(table.slug)`
   - Note: The slug will be generated from player name during seed (e.g., "mohamed-salah"). Duplicate names get `-{apiId}` suffix for uniqueness.

2. **Generate migration** by running `npx drizzle-kit generate` -- this will create a migration SQL file in `drizzle/`. The migration needs to:
   - Add the slug column (initially nullable since existing rows lack it)
   - Backfill slugs for all existing players using: `UPDATE players SET slug = LOWER(REGEXP_REPLACE(REPLACE(name, ' ', '-'), '[^a-z0-9-]', '', 'g'))` then handle duplicates by appending `-{api_id}`
   - Then set NOT NULL and UNIQUE constraints
   - If drizzle-kit generates a simple ADD COLUMN, manually edit the migration SQL to include the backfill steps

   The migration SQL should be structured as:
   ```sql
   ALTER TABLE players ADD COLUMN slug VARCHAR(150);
   UPDATE players SET slug = LOWER(REGEXP_REPLACE(REPLACE(name, ' ', '-'), '[^a-z0-9\-]', '', 'g'));
   -- Handle duplicates: append api_id for non-unique slugs
   UPDATE players p SET slug = p.slug || '-' || p.api_id
   WHERE p.slug IN (SELECT slug FROM players GROUP BY slug HAVING COUNT(*) > 1);
   ALTER TABLE players ALTER COLUMN slug SET NOT NULL;
   CREATE UNIQUE INDEX players_slug_idx ON players(slug);
   ```

3. **Run the migration** against local database: `npx drizzle-kit push` or apply the SQL directly.

4. **Create player queries** (`src/lib/players/queries.ts`):

   a. `getPlayerBySlug(slug: string)` -- Returns player profile data joined with team and league info. Returns null if player not found OR if player has fewer than 5 appearances (the thin content guard). Use raw SQL:
   ```
   SELECT p.*, t.name as team_name, t.slug as team_slug, t.logo_url as team_logo_url,
          l.name as league_name, l.slug as league_slug, l.current_season, l.logo_url as league_logo_url,
          (SELECT COUNT(DISTINCT fe.fixture_id) FROM fixture_events fe
           INNER JOIN fixtures f ON fe.fixture_id = f.id
           WHERE (fe.player_id = p.id OR fe.assist_player_id = p.id)
           AND f.league_id = l.id AND f.season = l.current_season) as appearances
   FROM players p
   INNER JOIN teams t ON p.team_id = t.id
   INNER JOIN leagues l ON t.league_id = l.id
   WHERE p.slug = $slug
   ```
   Return null if appearances < 5. Return typed `PlayerProfile` interface.

   b. `getPlayerSeasonStats(playerId: number, leagueId: number, season: string)` -- Returns aggregate season stats via raw SQL:
   - goals: COUNT of events where player_id matches and type IN ('goal', 'penalty_scored')
   - assists: COUNT of events where assist_player_id matches and type IN ('goal', 'penalty_scored')
   - yellowCards: COUNT where player_id matches and type = 'yellow_card'
   - redCards: COUNT where player_id matches and type = 'red_card'
   - appearances: COUNT(DISTINCT fixture_id) where player_id OR assist_player_id matches
   Return typed `PlayerSeasonStats` interface.

   c. `getPlayerRecentMatches(playerId: number, leagueId: number, season: string, limit: number = 10)` -- Returns last 10 matches the player appeared in (by kickoff DESC), with match events for that player. Two-step query:
   - First: get distinct fixture_ids where player has events, ordered by kickoff DESC, LIMIT 10
   - Second: for those fixtures, get match details (home/away teams, scores, kickoff, matchweek) + player's events in each (type, minute)
   Return typed `PlayerMatchInvolvement[]` with nested events array.

   d. `getQualifyingPlayerSlugs()` -- Returns slugs of all players with 5+ appearances (for generateStaticParams and sitemap). Use raw SQL counting distinct fixtures with events per player, HAVING >= 5. Only count events in the current season.

5. **Create server action** (`src/components/player-page/actions.ts`):
   - `fetchPlayerPageData(slug: string)` -- combines getPlayerBySlug, getPlayerSeasonStats, getPlayerRecentMatches
   - Guard with isDatabaseConfigured()
   - Localize team name via getLocalizedTeamNames (same pattern as leaderboard actions)
   - Return typed `PlayerPageData | null`

  Export types: `PlayerProfile`, `PlayerSeasonStats`, `PlayerMatchInvolvement`, `PlayerPageData`.
